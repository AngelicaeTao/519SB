# 519SB 聊天室

基于 Java 原生 HTTPS + SSE 的简易聊天室，支持账号系统、个人中心、图片消息、管理员控制台。外网访问统一通过 ngrok 转发。

## 功能特性

### 基础功能
- 门禁验证码（首次访问需输入 `519666233`，通过后 30 天免输）
- 账号注册、登录、修改密码
- 登录后自动进入聊天室

### 聊天功能
- 文字消息实时推送（SSE，服务器主动推给所有在线用户）
- 图片发送（前端自动压缩，最大宽度 800px，JPEG 质量 0.6）
- 图片点击放大预览，支持下载
- 消息带昵称、头像、时间戳
- 历史消息保留最近 200 条，持久化到 SQLite

### 个人中心
- 修改昵称（与账号分离）
- 上传/更换头像
- 修改密码

### 管理员控制台
- 查看所有用户列表（账号、昵称、身份、注册时间）
- 编辑用户（昵称、密码、头像、管理员权限）
- 删除用户（在线用户强制踢出，同时删除其所有消息）
- 查看指定用户的所有消息
- 单条消息删除 / 批量删除
